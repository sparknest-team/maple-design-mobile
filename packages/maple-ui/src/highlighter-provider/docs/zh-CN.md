

# HighlighterProvider

为代码展示子组件提供统一的语法高亮配置。

## 基础示例

### 基础用法

向 Code 子组件提供本地异步转换器；示例只转义并展示源码，不加载外部高亮服务。

```demo
../example/demos/basic.vue
```

## API

### 属性

| 参数              | 说明                                                        | 类型            | 默认值            |
|------------------|--------------------------------------------------------------|----------------|------------------|
| `highlighter`    | 着色器                                                       | `Highlighter`   | `-`              |
| `theme`          | 主题                                                         | _string_       | `-`              |
| `tag`            | 自定义标签名                                                  | _string_       | `div`              |

### 插槽

| 插槽名 | 说明 | 参数 |
| --- | --- | --- |
| `default` | 组件内容 | `-` |
