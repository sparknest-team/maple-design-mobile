# Server Side Rendering

### Intro

Here we introduce you to the basic way of introducing `Maple` into `Nuxt`.

### Create a Nuxt project

`Nuxt.js` is a server-side rendering application framework based on `Vue.js`. For detailed tutorials, please go to [Nuxt](https://nuxt.com).

### Nuxt Module

The first party of the component library provides [Maple Nuxt Module](https://nuxt.com/modules/maple) to support on-demand import and automatic import. Execute the following command to install it. After successful installation, nuxt related configuration will be automatically completed.

```shell
# playground-ignore
npx nuxi@latest module add maple
```
