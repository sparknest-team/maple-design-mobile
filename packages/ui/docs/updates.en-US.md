# Changelog

Check package versions and release notes before upgrading. Review affected props, events, types and theme variables, keep the dependency lockfile and verify critical workflows. Do not assume API compatibility without migration guidance.

## Release notes

[Read the full Changelog](https://github.com/sparknest-team/maple-design-mobile/blob/main/packages/ui/CHANGELOG.md) for features, fixes and breaking changes. Unreleased entries are not necessarily included in the current npm package.

## Upgrade checks

1. Identify your installed and target versions and read the changes between them.
2. Update affected props, events, types and theme variables.
3. Update the lockfile and verify builds and critical interactions before releasing your application.
