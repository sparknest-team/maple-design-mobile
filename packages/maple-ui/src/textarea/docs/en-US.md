# Textarea

### Introduction

A multiline plain-text editor for comments, feedback, and other longer content.

### Basic usage

```html
<script setup>
  import { ref } from 'vue'

  const value = ref('')
</script>

<template>
  <mp-textarea v-model="value" placeholder="Enter multiline text" />
</template>
```
