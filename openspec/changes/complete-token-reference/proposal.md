# Complete token governance and reference

## Why

Design decisions need a durable menu entry and exhaustive, source-linked component variable reference. Platform differences must be explicit rather than silently excluded from value checks.

## What Changes

- Govern all 64 system roles with shared defaults or explicit platform defaults.
- Check reviewed component defaults, preserving semantic dependencies when normalizing CSS syntax.
- Generate menu-accessible variable tables with public/internal classification, conditional declarations and compiled consumer evidence.
- Fail automated checks when references drift or unreviewed consumers appear.

## Impact

Documentation and validation are additive. Existing platform geometry and Message default emphasis remain intentional; separate component changes record removed obsolete APIs.
