# FormDetails

表单辅助信息，用于展示错误反馈与补充说明。

## API

### 属性

| 参数              | 说明      | 类型 | 默认值 | 
| ----------------- | --------- | --- | --- | 
| `error-message` | 错误信息    | _string_ | `-` |
| `extra-message` | 附加信息 | _string_ | `-` |

### 插槽

| 插槽名 | 说明 | 参数 |
| --- | --- | --- |
| `extra-message` | 附加信息 | `-` |
