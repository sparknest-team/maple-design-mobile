# Maple Resolver

English | [简体中文](./README.zh-CN.md)

`@maple-design/resolver-vue` is a resolver for [unplugin-vue-components](https://github.com/unplugin/unplugin-vue-components) that enables on-demand importing of Maple components.

## Features

- Supports `Vite`, `Webpack`, `Vue CLI`, `Rollup`, `esbuild`, and more.
- Automatically imports the corresponding CSS styles for the components.
- Supports SSR (Server-Side Rendering).

## Automatic Import

via plugin
[unplugin-vue-components](https://github.com/antfu/unplugin-vue-components) and
[unplugin-auto-import](https://github.com/antfu/unplugin-auto-import)
Implement components to automatically import on demand, This is our most recommended way.

### Install Plugin

```shell
# npm
npm i @maple-design/resolver-vue unplugin-vue-components unplugin-auto-import -D

# yarn
yarn add @maple-design/resolver-vue unplugin-vue-components unplugin-auto-import -D

# pnpm
pnpm add @maple-design/resolver-vue unplugin-vue-components unplugin-auto-import -D
```

### Vite

```js
// vite.config.js
import vue from '@vitejs/plugin-vue'
import components from 'unplugin-vue-components/vite'
import autoImport from 'unplugin-auto-import/vite'
import { MapleResolver, MapleStyleImports } from '@maple-design/resolver-vue'
import { defineConfig } from 'vite'

export default defineConfig({
  plugins: [
    vue(),
    MapleStyleImports(),
    components({
      resolvers: [MapleResolver()]
    }),
    autoImport({
      resolvers: [MapleResolver()]
    })
  ]
})
```

### Vue CLI

```js
// vue.config.js
const Components = require('unplugin-vue-components/webpack')
const AutoImport = require('unplugin-auto-import/webpack')
const { MapleResolver } = require('@maple-design/resolver-vue')

module.exports = {
  configureWebpack: {
    plugins: [
      Components.default({
        resolvers: [MapleResolver()]
      }),
      AutoImport.default({
        resolvers: [MapleResolver()]
      })
    ]
  }
}
```

### Typescript configuration note

In order to get good IDE syntax highlighting,
please make sure that the type declaration files generated by the above two plugins are include by `typescript`,
which can be configured as follows in `tsconfig.json`:

```json
{
  "include": ["auto-imports.d.ts", "components.d.ts"]
}
```

### Manual import

Each component is a `Vue plugin` and consists of `component logic` and `style files`, which are manually imported and used as follows.

```js
import App from './App.vue'
import { createApp } from 'vue'
import { Button } from '@maple-design/ui-vue'
import '@maple-design/ui-vue/button/style'

createApp(App).use(Button)
```

OR

```html
<script setup>
import { Button as VarButton } from '@maple-design/ui-vue'
import '@maple-design/ui-vue/button/style'
</script>

<template>
  <mp-button>Say Hello</mp-button>
</template>
```

### Manual import and automatic import comparison

#### Comparison-Manual import

```html
<script setup>
import { Button as VarButton, Message } from '@maple-design/ui-vue'
import '@maple-design/ui-vue/button/style'
import '@maple-design/ui-vue/message/style'

function handleClick() {
  Message('Hello!')
}
</script>

<template>
  <mp-button @click="handleClick">Say Hello</mp-button>
</template>
```

#### Comparison-Automatic import

```html
<script setup>
function handleClick() {
  Message('Hello!')
}
</script>

<template>
  <mp-button @click="handleClick">Say Hello</mp-button>
</template>
```

## Explicit-import styles (Vite)

MapleStyleImports() handles named value imports from @maple-design/ui-vue after Vue/TypeScript compilation, using the same style mapping as MapleResolver. It supports aliases, components, deduplication and importStyle:false. Type-only, namespace and default imports are excluded. Add it to Vite plugins, not the resolvers array. Maple CLI docs include it by default; restart the dev server after updating CLI plugins.
