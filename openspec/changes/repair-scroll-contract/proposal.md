# Scroll and text numeric contracts

Affix distinguishes finite JS-resolved units from native sticky CSS and provides safe conversion/diagnostics without widening shared utilities. BackTop validates finite nonnegative duration and real easing presets, clamps finite custom results and falls back to linear progress for nonfinite results while preserving thrown callback errors. Ellipsis accepts only click triggers and finite rows >=1, floors decimals, safely uses single-line fallback. Keep controlled notifications, lifecycle and tooltip defaults.
