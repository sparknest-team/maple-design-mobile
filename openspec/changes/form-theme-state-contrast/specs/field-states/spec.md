# Form theme state contrast

All eight Maple theme keys must be verified against the actual root color scheme. Selection summaries, active labels and clear actions use readable content roles; action background colors are not foreground text defaults. Enabled field content and focused/error floating labels target 4.5:1; check/clear icons target 3:1. Disabled content is measured separately.

Alps and Firefly outline, filled and standard variants support normal, hover, focus, error, disabled and readonly states. Filled focus and hover surfaces are distinct; standard has a visible baseline. Brand state adaptations are documented separately from sampled Horo colors.

The theme page keeps a compact booking preview and exposes independent variant and size controls; the shared comparison exposes five sizes, three variants and disabled/readonly/error switches. Checkbox adds a public mark-color role in both independent libraries, preserving Cedar's existing default while Maple selects a contrasting foreground.
