# Atomic CSS

### Intro

| Layer | Package | When |
| ---------------------- | -------------------------------------------------------------------- | ---------------------------------------- |
| Fixed utilities `mp-*` | `utilities.css` | Use without Uno/TW |
| Uno / TW preset | `@maple-design/preset-unocss` / `@maple-design/preset-tailwindcss` | Full atomic system with the `mp-` prefix |

Phone preview uses the same CSS variables; real classes are generated by Uno/TW.
Both engines use the same names, such as `mp-flex`, `mp-p-16`, `mp-text-md`, and `mp-bg-primary`.
Tailwind's `prefix` is global, so one Tailwind instance cannot load the Cedar and Maple presets together; choose the preset for the current app.

Cedar: `@cedar/preset-*` with `c-` prefix.

Daily class cheat sheet: [Common Utilities](#/en-US/atomic-usage).

```js
// playground-ignore
import '@maple-design/ui/es/utilities/utilities.css'
```

### Starter example

Choose either UnoCSS or Tailwind. The utility names inside components are identical:

```vue
<template>
  <div class="mp-flex mp-max-w-md mp-flex-col mp-gap-12 mp-rounded-lg mp-border mp-border-solid mp-border-gray-200 mp-bg-body mp-p-16">
    <h3 class="mp-m-0 mp-text-lg mp-text-primary">My first atomic card</h3>
    <p class="mp-m-0 mp-text-sm">Combine small utilities instead of writing component CSS.</p>

    <div class="mp-flex mp-items-center mp-justify-between mp-gap-8 mp-rounded-md mp-bg-gray-100 mp-p-12">
      <code>mp-flex mp-items-center mp-gap-8</code>
      <span class="mp-text-success">Success</span>
    </div>

    <mp-button class="mp-rounded-md mp-border-0 mp-bg-primary mp-px-16 mp-py-8 mp-text-white hover:mp-opacity-80">
      Save
    </mp-button>
  </div>
</template>
```

Read it from left to right: `mp-` is the Maple prefix; `flex` controls layout; `p/px/py/gap` control spacing; `bg/text/border` control colors; `rounded` controls radius; and `hover:` is a state variant.

### UnoCSS

```js
// playground-ignore
import { presetMaple } from '@maple-design/preset-unocss'
import { defineConfig } from 'unocss'

export default defineConfig({
  presets: [presetMaple()],
})
```

### Tailwind CSS

```js
// playground-ignore
import { presetMaple } from '@maple-design/preset-tailwindcss'

export default {
  content: ['./index.html', './src/**/*.{vue,js,ts,jsx,tsx}'],
  presets: [presetMaple()],
}
```

### Class catalog

Colors: `mp-bg-primary` `mp-text-success` `mp-bg-body` …  
Font: Uno / Tailwind `mp-text-md`  
Spacing / Size: values map directly to pixels (`1 = 1px`), such as `mp-p-8` (8px), `mp-h-10` (10px), `mp-w-full` (100%)  
Overflow: `mp-overflow-hidden`, `mp-truncate`, `mp-line-clamp-2`  
Breakpoints: `sm:` `md:` `lg:` `xl:` (768 / 992 / 1200 / 1920)

The phone preview includes a numeric spacing demo for 4px, 8px, 16px, and independent horizontal/vertical padding.

```html
<!-- playground-ignore -->
<template>
  <div class="mp-bg-body mp-text-1 mp-text-md">
    <span class="mp-text-primary">primary</span>
    <div class="mp-bg-primary sm:mp-bg-info md:mp-bg-warning">maple</div>
  </div>
</template>
```
