## API

### Props

| Arguments | Description | Type | Default |
| ------------------ | -------------------------------------------------------------- | ---------------- | ------------------ |
| `highlighter` | Code Highlighter | `Highlighter` | `-` |
| `theme` | Code Theme | _string_ | `-` |
| `tag` | Custom tag name | _string_ | `div` |

### Slots

| Slot | Description | Arguments |
| --- | --- | --- |
| `default` | Component content | `-` |
