# 职责与行为

Form 管模型、重置和整体提交；FormItem 管标签和候选校验；字段拥有草稿与唯一的确认提交。字段属性 > FormItem > Form，readPretty 的 false 可覆盖父级 true。readonly 保留原控件外观并禁止改动；disabled 保留禁用外观；readPretty 仅渲染格式化值和 read 插槽，不挂载输入或启动搜索。

Cedar click/dblclick 使用固定定位的 Teleport 覆盖原字段，保留原字段占位；显示原始控件而不是另造弹窗列表。覆盖层可扩宽但限制在视口内，跟随滚动和尺寸变化；没有模态遮罩或独立编辑按钮。Enter/F2 可进入；取消/Escape 丢弃草稿；确认提交。多行文本保留 Enter 换行。

Maple inline 直接编辑，popup 使用整行值入口和独立移动面板；标题默认请输入/请选择，左标题右关闭，底部确认。搜索仍由字段完成：Cedar 使用原控件搜索，Maple 搜索在弹层内；异步搜索不会更改已提交值。

确认先校验候选值，再执行 beforeCommit。异步期间冻结输入和操作，拒绝或校验失败保留草稿；重置、外部替换、展示或状态变化取消当前事务并使延迟结果失效。日期和时间在原位事务内即时更新草稿，关闭内部确认，外层只确认一次。独立面板行为不受影响。
